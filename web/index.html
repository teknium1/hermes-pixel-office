Hermes Pixel Office Enhanced — v1.3.2

ORIGINAL PLUGIN

Hermes Pixel Office was originally created by Teknium — a pixel-art virtual office that turns every Hermes agent into an animated character at a desk. This fork, Hermes Pixel Office Enhanced, builds on that clean foundation and takes it further.

teknium1/hermes-pixel-office
THE ENHANCEMENT — BY DRGEKOZ

I'm DrGekoz. I made Hermes IdleViber, a cozy pixel idle game. When the office came along, I started adapting the bits of IdleViber I love most — its tier ladder, all 500 pixel icons, and its peer-to-peer mesh — into the plugin. So the office became a place you can actually live in: a GitHub leaderboard, a 500-rung tier ladder, office chat, and custom profiles and themes, all shared with friends.

MULTIPLAYER — FREE CLOUDFLARE RELAY

Leaderboards, chat and profiles now ride a free Cloudflare relay (Workers + Durable Object) that everyone can write to over plain HTTPS. That means it works on any network — no port-forwarding, no TURN, no WebRTC required — and it keys the board by GitHub username, so the same account shows once even across multiple browsers or machines. WebRTC still runs underneath for low-latency realtime when peers can reach each other directly. Zero config: connect your GitHub and you're on the shared board automatically. The whole board is also backed up to a gist every 10 minutes.

JEKYLL-HYDE — COMPLETION AUDITOR

This office has built-in support for Jekyll-Hyde, a Hermes plugin by jnorthrup (Jim Northrup) that audits agent completion and drives verified next actions. Install it to start feeding the Model Leaderboard (Models button), which ranks models by how much Hyde has had to correct them — the most-corrected model sinks to the bottom. Each row shows the sandbagged / genuine / uncertain verdict breakdown. The board rides the P2P mesh, so peers' audit data merges in.

CONNECT GITHUB✕
Logs in with the GitHub account this machine is authenticated as, so your real username + avatar show on the leaderboard. Logging in is what lets your scores and chat reach other users over P2P. Click your name in the top bar to open your profile.
